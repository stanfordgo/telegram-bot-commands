1. 权限说明

命令鉴权由 judgeRole(uname, flag) 完成，权限（以 @用户名 为 key，cardType 为角色值）.

标记 含义 通过条件
0 管理员级命令 用户角色 cardType == "0"（超管）
1 操作员级命令 用户角色为 "0"（超管）或 "1"
3 无需鉴权 任何人均可触发（如查单回复）
公开 源码注释了鉴权 实际对所有人开放
cardType == "0" 为超级管理员，可通过任意权限校验；其它角色仅能通过与自身 flag 精确匹配的命令。消息入口

15. 自动传单（图片消息）

向群内发送带说明文字（caption）的图片时，机器人自动解析说明中的商户单号（正则 [a-zA-Z0-9_\-]{7,}）：

  • 若订单已支付成功/完成 → 回复「已支付成功 | 待回调 / 已回调」。
  • 若订单待处理 → 复制图片转发到绑定的上游渠道群，并记录查单记录；若开启催单，则进入催单流程。
  • 渠道群回复该图片消息时，机器人会把回复内容回传到对应商户群。
若发送者在传单屏蔽名单中，则忽略该图片消息。
